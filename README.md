# Chapter 20 Interactive Sociology Activity

## People, Places & the Planet

A browser-based interactive reading activity covering:

- 20.1 Demography and Population
- 20.2 Urbanization
- 20.3 The Environment and Society
- Fertility, mortality, and migration
- Malthusian, cornucopian, zero population growth, and demographic transition theories
- Refugees, asylum-seekers, and internally displaced people
- Suburbs, exurbs, urban sprawl, and gentrification
- Functionalism, conflict theory, and symbolic interactionism
- Fracking and environmental inequality
- Final Alien Eyes Training Manual mission

### Student Features
- Short reading chunks
- Immediate retrieval practice
- Instant quiz feedback
- XP and progress tracking
- Real-world scenarios
- Lived-experience reflections
- Zoom In / Zoom Out sociological analysis
- Three sociological perspective practice
- Print/Save Responses option

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the published activity URL.

No libraries, installation, server, or build process are required.
